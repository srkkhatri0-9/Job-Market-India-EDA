# Job Market EDA: What Do AI/ML Roles Actually Ask For?

## Why I built this
I'm preparing for ML/AI Engineer roles and wanted real data on what skills are actually being asked for, instead of guessing 
from job descriptions alone and also want to execute what I am learning in this journey practically.
## What it does
Scrapes and analyzes 500 job postings for ML/AI Engineer roles across 
India and remote markets, then explores what skills, tools, and experience 
levels actually show up most.

## Status
In progress — learning project, updated as I go.

## Tech stack
Python, BeautifulSoup, pandas, Seaborn, SQL, Streamlit

## How to run
\`\`\`bash
